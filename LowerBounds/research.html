Research log: counting states instead of steps

Outcome, stated up front. I did not find a new superlinear lower bound for a natural NP problem in an unrestricted model. Here is what this attempt produced:

  1. A tight time-versus-states tradeoff for palindromes on one-tape machines, $T = \Theta(n^2/\log q + n)$. It holds even if the machine is built separately for each $n$, and the matching machines are checked by the code below. I could not find it stated in this form, but it is very likely folklore.
  2. A barrier, proved below: every crossing-sequence argument stops at $n^2/\log q$, and getting a superlinear bound for multitape machines requires beating $n^2$ on one tape. Together these show exactly how far the proof on the main page can be pushed.
  3. Three genuinely different attempts to get past the barrier, each with the precise point where it breaks.

The idea: treat states as a lookup-table budget

Lower bounds are usually stated for one fixed machine, and the number of states $q$ gets absorbed into the constant. Here $q$ is a resource in its own right: a machine with $q$ states can keep a lookup table, or a buffer, of about $\log_2 q$ bits in its finite control. The question is how much that buys. For palindromes the answer is "exactly a $\log q$ factor, no more". That pins down what a new technique has to do.

Theorem 3: the tradeoff is tight

Theorem 3. Let $T(n,q)$ be the minimum worst-case time of a deterministic one-tape Turing machine with $q$ states deciding PAL on inputs of length $n$. The machine may depend on $n$, and its tape alphabet may be any constant size. Then for all $q \ge 8$ and all large $n$, $$ T(n, q) = \Theta\!\left(\frac{n^2}{\log q} + n\right). $$

Lower bound. The proof of Theorem 1 never uses the fact that one machine works for every $n$. It only uses one deterministic machine on inputs of one length. It gives an average running time of at least $(m+1)(1-2^{-m/2})\lfloor m/(2\log_2 q)\rfloor$ with $m = \lfloor n/3\rfloor$. That is $\Omega(n^2/\log q)$ whenever $\log_2 q \le m/4$. For the $+\,n$ term: on a palindrome, the machine must visit cell $n$. Otherwise, flipping that bit would leave the run unchanged and the machine would accept a non-palindrome. Reaching cell $n$ from cell $1$ takes $n-1$ steps. Upper bound. Fix a buffer size $k$. The machine repeatedly does the following. It reads the $k$ leftmost unconsumed symbols into its state, marking them consumed. It walks right to the last unconsumed symbol. It checks the $k$ rightmost unconsumed symbols against the buffer in reverse order, marking them. Then it walks back. When fewer than $2k$ symbols remain, it checks the leftover middle inside its state. Each round costs $O(n)$ and consumes $2k$ symbols, so the time is about $n^2/(2k) + O(n)$. The state count is $q = 2^k(k+2) + O(1)$, so $k = \Theta(\log q)$. ∎

Checked by code. pal_tradeoff.py builds the full transition table of this machine for a given $k$, so the state count $q$ is exact rather than estimated. It runs the machine on every binary string of length up to 16 and compares each answer with the true palindrome test. All machines answer correctly. On long palindromes, the product $T \cdot \log_2 q / n^2$ settles to a constant, as Theorem 3 predicts:

Proposition 4: one tape and many tapes, with states counted

Proposition 4 (block simulation). Suppose a $k$-tape machine $M$ decides $L$ in time $t(n) \ge n$. Then for every window size $w \ge 1$ there is a one-tape machine with $2^{O(kw)}$ states that decides $L$ in time $O(t^2/w + t)$. The constants depend on $M$.

Store the $k$ tapes as tracks on the single tape, with a marker for each head. Each phase sweeps once across the at most $2t+1$ cells in use and copies into the state the $2w+1$ cells around each head. It then simulates $w$ steps of $M$ entirely inside the state, which is safe because no head can leave its window within $w$ steps. Finally it sweeps back, writing the windows and the moved head markers onto the tape. A phase costs $O(t + kw)$ steps, and there are $\lceil t/w \rceil$ phases. The state holds $k$ windows over a constant-size alphabet, giving $2^{O(kw)}$ states. ∎

Corollary. Taking $w = 1$: if some problem in NP needs $\omega(n^2)$ time on one-tape machines, then it needs $\omega(n)$ time on multitape machines. More generally, if every one-tape machine with $q$ states needs time $g(n)\, n^2/\log q$, then every multitape machine needs time $\Omega(n\sqrt{g(n)})$. PAL is exactly the case $g = \Theta(1)$, which matches the fact that it takes linear time on two tapes.

Proposition 5: the crossing-sequence barrier

Proposition 5. Call a cut argument any lower bound of the form "$T \ge \sum_i \log_2 F_i / \log_2 q$", where $F_i$ is the size of a fooling set at boundary $i$. A fooling set is a set of inputs such that for any two of them, $ab$ and $cd$ split at boundary $i$, at least one of the hybrids $ad$ or $cb$ gets a different answer than the originals. By Lemma 2, their crossing sequences must then all differ. Theorem 1 is an argument of this kind. For every language, such an argument proves at most $n^2/(4\log_2 q)$.

If two inputs $ab$ and $cb$ in a fooling set had the same right part $b$, the hybrids would be $ab$ and $cb$ themselves, so no answer changes. So the members of a fooling set have distinct right parts, and likewise distinct left parts. Hence $F_i \le 2^{\min(i,\, n-i)}$, and $\sum_i \min(i, n-i) \le n^2/4$. ∎

Combine Propositions 4 and 5. Cut arguments can never reach the $\omega(n^2)$ that the corollary needs, and Theorem 3 shows PAL already sits at the barrier. So no amount of cleverness inside the crossing-sequence method can produce a superlinear multitape lower bound. A new technique has to charge the machine for computing, not only for moving information across a cut.

Three attempts to charge for computation

Attempt A: direct sums and interleaving

Idea. Interleave many independent palindrome instances, so that every cut has to carry information about all of them at once, and hope the costs add up.
Where it breaks. Proposition 5 applies to any language, including interleaved ones. A cut still separates at most $n$ input bits, so the total stays at most $n^2$. Interleaving only rearranges the same budget. Dead end, provably.

Attempt B: charge computation through circuits

Idea. If deciding $L$ on the gathered data requires a large circuit, a one-tape machine should pay for that circuit in time.
Where it breaks. The conversion runs the wrong way for us. A one-tape machine running in time $T$ (it is in particular a multitape machine) can be turned into a circuit of size about $T \log T \cdot \mathrm{poly}(q)$, using the Pippenger–Fischer oblivious simulation. So proving $T = \omega(n^2)$ this way would need an explicit circuit lower bound of about $n^2$. The best known is about $3.1n$. Circular: it needs a much stronger result than it gives.

Attempt C: hardness magnification

Idea. For certain versions of MCSP (the problem of deciding whether a truth table has a small circuit), McKay, Murray and Williams (STOC 2019) showed that even an $N^{1.01}$ lower bound against one-tape machines would imply P ≠ NP. This is far below the $n^2$ that crossing sequences give for palindromes, so the target looks tiny.
Where it breaks. Chen, Hirahara, Oliveira, Pich, Rajgopal and Santhanam (the "locality barrier", ITCS 2020) observed that essentially all known lower-bound techniques also work against machines with small local oracles, and machines of that kind can solve the magnified problems. So no known technique can prove these targets, however small the exponent looks. Proposition 5 is a concrete instance of that barrier: crossing sequences are local. The most promising direction, and the one where I have nothing new to add.

Where this leaves things

  • SAT on random-access machines: even a linear-time algorithm has not been ruled out (van Melkebeek's survey).
  • Multitape machines: the best separation of nondeterministic from deterministic time is Santhanam's $\mathrm{NTIME}(n\sqrt{\log^* n}) \ne \mathrm{DTIME}(n\sqrt{\log^* n})$. Reaching SAT would need roughly a polylog gap here, because reducing a nondeterministic linear-time computation to SAT blows up its size by polylog factors.
  • One tape: by the corollary above, any $\omega(n^2)$ bound for SAT would already give a superlinear multitape bound for SAT.

The contribution of this attempt is a clean target. Any new method must show that, for some NP problem, extra states (lookup tables) help a one-tape machine by less than a $\log q$ factor. That is, $T \cdot \log q = \omega(n^2)$. Palindromes show that this fails for any method that only counts information crossing cuts.

Round 2: looking where the barriers are thinner

Outcome. Still no new superlinear lower bound for an NP problem. Round 2 produced three things:

  1. A map of open lower-bound questions that have no known formal barrier.
  2. A correction to the main page: a natural NP-complete problem is already known not to be solvable in linear time on multitape machines.
  3. A small proved result, checked by brute force. For linear functions, the Mittal–Raz route to multitape lower bounds is exactly as hard as matrix rigidity. So any candidate for that route should be nonlinear.

Proposition 6: linear block rigidity reduces to matrix rigidity

Mittal and Raz showed that a block-rigid function cannot be computed by multitape Turing machines in linear time, even with advice. Here is my version of the definition; it may differ in details from theirs.

Write the input as $k$ blocks of $n$ bits. Call $f$ $(r,s)$-decomposable if a hint $h(x)$ of $r$ bits can be chosen, as any function of the input at all, such that each output block $j$ is a function of the hint and of at most $s$ input blocks $x_{S_j}$. Block rigidity means not decomposable with a small hint and small $s$.

Take $f(x) = Ax$, where $A$ is a $k \times k$ matrix over the field $\mathbb{F} = \mathrm{GF}(2^n)$, so each block is one field element.

Lemma. Let $X$ be any set of inputs on which every output $(Ax)_j$ is a function of $x_{S_j}$ alone. For any set $J$ of outputs, let $W = \bigcup_{j \in J} S_j$ and $C = [k]\setminus W$. Then $|X| \le |\mathbb{F}|^{\,k - \operatorname{rank} A[J,C]}$.

Consequences.

  1. If $f$ is $(r,s)$-decomposable, then for every such $J$, $\operatorname{rank} A[J,C] \le r/n$. This holds even though the hint is allowed to be nonlinear.
  2. If $A$ is a Cauchy matrix (needs $2^n \ge 2k$), then $f$ is not $(r,s)$-decomposable whenever $(\lfloor r/n\rfloor+1)(s+1) \le k$.
  3. Conversely, if $A = S + L$ where $S$ has at most $s$ nonzeros per row and $\operatorname{rank} L \le \rho$, then $f$ is $(\rho n, s)$-decomposable.

Lemma. For $j \in J$, write $(Ax)_j$ as the sum over columns in $W$ plus the sum over columns in $C$. The left side and the first sum are both functions of $x_W$, so $A[J,C]\,x_C$ is a function of $x_W$ on $X$. Fixing $x_W$ therefore confines $x_C$ to one coset of $\ker A[J,C]$. Counting: $|X| \le |\mathbb{F}|^{|W|}\cdot|\mathbb{F}|^{|C|-\operatorname{rank}A[J,C]}$, and $|W| + |C| = k$. (1) Fix the most common hint value. On those inputs $X$ the decomposition is local, and $|X| \ge 2^{nk-r}$. (2) In a Cauchy matrix every square submatrix is nonsingular. Take $|J| = \lfloor r/n\rfloor + 1$. Then $|C| \ge k - s|J| \ge |J|$, so $\operatorname{rank}A[J,C] = |J| > r/n$, which contradicts (1). (3) Write $L = PQ$ with $Q$ having $\rho$ rows, and use the hint $h(x) = Qx$, which is $\rho$ field elements. Then $(Ax)_j = (Sx)_j + P_j\,h(x)$. ∎

Checked by code. block_rigidity_check.py tests random matrices over GF(2), the case $n = 1$, with $k \le 4$. For every choice of the sets $S_j$ it finds the largest valid $X$ by exhaustive search. The lemma held in all 20,951 cases and was exactly tight in 13,416 of them.

What this means. For linear functions there are two sides:

  • The best lower-bound method available is (1), the "untouched submatrix" method. That is the same method classical rigidity proofs use.
  • Any failure of matrix rigidity hands over a decomposition, by (3).

So linear candidates run straight into the decades-old rigidity barrier. Explicit matrices only reach "hint size × locality ≈ $k$", shown by the Cauchy bound. The trivial decomposition only needs "hint size + locality $= k$". The real gap is between a product and a sum.

Takeaway: candidates for block rigidity should be nonlinear, and as far as I can tell from the abstracts, the parallel-repetition functions Mittal and Raz study are. I couldn't read the exact parameters the Turing-machine application needs, so I can't say how far the Cauchy bound falls short.

What I would try next

  1. Off-line one-work-tape machines. Aim for an $n^{1+\varepsilon}$ bound for deciding whether $B = A^{T}$. Bounds there are weak, no barrier is known, and no hardness-magnification trap is known.
  2. Nonlinear block rigidity at small sizes. Use exhaustive search, like the script above, to test whether natural nonlinear candidates (polynomial evaluation, products over a field) beat the linear "product ≈ $k$" bound for small $k$.
  3. Depth-2 GF(2) circuits. Look for a polynomial-time construction of a matrix that needs $n^{1+\varepsilon}$ wires. Small cases can be solved exactly with SAT solvers.

Round 3: the limits of counting, and a hint of something beyond

Outcome. Still no new lower bound for an NP problem. Round 3 produced three things:

  1. A proved limits-of-the-method theorem. The counting argument behind Proposition 6 cannot certify block rigidity beyond "hint × locality $\approx k\log k$", for any function. Explicit functions already reach "hint × locality $\approx k$".
  2. Experiments on all small cases. The true answers beat what that method can certify, by more for nonlinear functions, and by more as $k$ grows.
  3. A verified example where, even for a linear map, the largest valid input set is not a subspace. So rank arguments do not capture the exact quantity.

Together these point to one specific missing ingredient, described at the end of this round.

Proposition 7: what the counting method can never do

The counting method (Proposition 6, in the general form) certifies that $f$ is not $(r,s)$-decomposable with dependency pattern $S$ by exhibiting one set $J$ of outputs. Fix the inputs $W_J$ that $J$ is allowed to see. The method then needs the values $f_J$ to carry more than $r$ bits of min-entropy over the untouched inputs $C_J$. Those values can carry at most $n\cdot\min(|J|,|C_J|)$ bits, whatever $f$ is.

Proposition 7. Let $\rho = \lfloor r/n \rfloor$. If $s > \dfrac{2k}{\rho+1}\ln\dfrac{ek}{\rho+1}$, there is a dependency pattern $S$ with $|S_j| = s$ on which the counting method fails, for every function $f$ simultaneously. So the method can only work while $\rho\cdot s = O(k\log(k/\rho))$. Cauchy matrices show that it does work up to $(\rho+1)(s+1) \le k$, so the method is understood up to the log factor.

The method fails on $S$ if every $\rho+1$ of the sets $S_j$ together cover all but at most $\rho$ blocks. Then every $J$ has either $|J| \le \rho$ or $|C_J| \le \rho$, so $\min(|J|,|C_J|) \le \rho$ and the min-entropy is at most $n\rho \le r$. (A larger $J$ only shrinks $C_J$.) Choose each $S_j$ uniformly at random. For a fixed set $D$ of $\rho+1$ blocks, each $S_j$ avoids $D$ with probability at most $e^{-s(\rho+1)/k}$. The pattern fails to be covering only if some $D$ is avoided by some $\rho+1$ of the sets. By a union bound, that probability is at most $\binom{k}{\rho+1}^2 e^{-s(\rho+1)^2/k} \le \left(\tfrac{ek}{\rho+1}\right)^{2(\rho+1)} e^{-s(\rho+1)^2/k}$, which is below $1$ under the stated condition on $s$. ∎

Observation: rank is not the whole story, even for linear maps

For random linear maps the largest valid set had power-of-two size in 609 of 610 cases, which is consistent with it being a subspace. The exception is real and was checked by plain brute force:

  • The map over GF(2) has rows $01100, 00011, 10111, 10010, 10001$.
  • The pattern is $S = (00110, 00011, 11000, 11000, 00011)$.
  • The largest valid set is $\{00000, 00101, 01010, 10111, 11011\}$, with 5 elements. It is not closed under XOR.
  • The best subspace or coset has only 4 elements, and no valid set of size 6 exists.

In this instance the hint still needs 3 bits either way: covering all 32 inputs with sets of at most 5 takes 7 sets. So this does not show nonlinear hints winning. It shows that the exact quantity is not a rank quantity, so linear-algebra methods alone cannot pin it down even for linear maps.

The missing ingredient

Proposition 7 says any argument built from one output set at a time stops at hint × locality $\approx k\log k$. The experiments say the truth lies beyond that, increasingly so for nonlinear functions. What is needed is an inequality that combines many output sets at once, in the spirit of Shearer's lemma, or a "direct product" argument that charges each extra output a little. For Turing machines this is exactly the content of the strong multiplayer parallel-repetition conjecture. The small-case data suggests the explicit quadratic map above is a reasonable test case for such an inequality.
